# Template HyperFrames — Giải mã tin chứng khoán

Mỗi bài chỉ cần thêm `hf-data.json` vào `slide/giai-ma-tin-tuc-<chude>-<ddmm>/`
(mẫu: `hf-data.sample.json`, khoá `"template": "giaima-tin-hf"`).
Script giữ đúng 9 dòng, số câu 1,3,3,3,4,4,3,3,3 như master. Mỗi khối hiện ra đúng lúc
câu tương ứng được đọc (đọc từ mốc thời gian từng chữ, `beat` = số thứ tự câu trong dòng, đếm từ 0).
9 cảnh: hook · tờ báo nguồn (tiêu đề gõ chữ, bút dạ quang) · thẻ số liệu đếm số · thanh thắng/thua ·
3 thẻ tác động (sáng lần lượt) · cột đèn giao thông · chuỗi nguyên nhân → kết quả · checklist F0 · outro + nguồn + miễn trừ.
